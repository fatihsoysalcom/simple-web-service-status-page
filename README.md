# Simple Web Service Status Page

This example creates a simple, single-file HTML page that simulates a service status dashboard. It displays the health of various components (e.g., API, Database, Web Application) and allows for simulating status changes like outages, degraded performance, and scheduled maintenance. This demonstrates the core concept of a status page: providing transparent and real-time information about service availability.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any web browser.
